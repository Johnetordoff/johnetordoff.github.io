Project concept

Speed Birdwatching / Speedrunning Every Bird

A “Big Year” performed entirely on a computer screen, as fast as human perception allows. A program would flash identifiable bird images in sequence while a timer measures the run.

The joke is to treat this with the seriousness of both competitive birding and speedrunning: categories, splits, verification, and records. The images still have to be perceived or recognized; merely loading thousands of images does not count as observing the birds.

Possible rules to test

  • A continuous run lasting for a full song, or another fixed presentation period.
  • Identification or species-name verification in presentation order.
  • A timed challenge with repeatable sequences and clear observation criteria.

This page describes the planned project. It does not claim a completed program or a world record.

Book and research in progress

Buddy: Body Bags and Bounties: The Buddy Ryan Story

A biography and research project about Buddy Ryan, assembled from books, documents, articles, and moving images.

The research starts with a timeline from his birth onward. Claims should stay attached to their sources so that a reader can follow the evidence behind the story. Building that source-cited chronology is part of writing the book.

Private system under development

My Total Data

Git without GitHub: my private Git ecosystem and website for listing, browsing, and managing my own repositories and their history.

The current plan is a self-hosted Git server on the ODROID, with a top-level repository registry that points to separate project and archive repositories. GitHub can remain a parallel mirror or backup while the private system develops.

The managed data belongs in repositories: ordinary project and archive files, with source records and provenance preserved. Operating-system files and unrelated machine state are outside this system's data scope.

Operating-system experiment in progress

JetOS

A standalone operating-system and language experiment built around Python and a command-line-first workflow. Docker and QEMU provide portable development paths; Gentoo and CPython are part of the exploration.

The long-term direction favors Python, small native components where necessary, and independent machines for workloads that need them. Self-contained builds and explicit, frozen inputs are part of the design.

These are project notes, not a browser-playable operating system or a completed hardware release.

Game and world-generation work in progress

Megalomania: Planet Generation

A world-generation and simulation project in which deterministic seeds create planets, terrain, and the worlds the game will inhabit. Planets should also be generated independently for inspection and editing.

The broader game begins with one person in a prehistoric world of autonomous people. A headless simulation server and a separate visualizer support the aim of scaling toward very large populations while keeping cause and effect inspectable.

The planet generator's playable web address has not yet been connected here.
