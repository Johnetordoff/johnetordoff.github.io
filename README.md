# John Tordoff's websites

- [Current Windows 95 personal site](https://john-tordoff.johnetordoff.chatgpt.site)
- [Crazy Projects](https://john-tordoff.johnetordoff.chatgpt.site/#crazy-projects)
- [Restored whale/VHS website](https://johnetordoff.github.io/old-website/)
- [Project notes](https://johnetordoff.github.io/project-notes/)

The current personal site has an **Old Website** desktop shortcut. The restored
VHS website is also preserved in this repository under `old-website/`.

The restoration starts from the original `index3.html`: all four slides, the
embedded whale mural photograph, the television frame, the VCR OSD font, and
the original tracking/glitch effects. Its old biography text is identified as
historical content. Dependencies are bundled locally; the obsolete analytics
tag is removed. The original root page and the historical source files remain
available.

The project notes cover Speed Birdwatching, *Buddy: Body Bags and Bounties:
The Buddy Ryan Story*, My Total Data, JetOS, and Megalomania. Planned features
are described as plans.
